# Gerador de Senhas
Scripts em python para gerar senhas e wordlist incluindo aleatoriedade

## password.py 
- Gera uma única senha por execução

## wordlist.py
- Cria uma lista de senhas de acordo com a quantidade de palavras informada pelo usuário.

## passwl.py
- Iclui as duas funcionalidades anteriores num único script que interage com o usuário perguntando se o mesmo desejar criar uma senha ou gerar uma wordlist.
- Caso a wordlist tenha a quantidade de palavras menor que 30, ela será exibida na tela.
